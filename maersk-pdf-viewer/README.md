#  Maersk PDF Viewer – Frontend Assignment

A responsive React web application that displays the **Maersk Q2 2025 Interim Report (PDF)** and allows users to highlight specific text phrases when clicking related reference items.

This project was built as part of the **Fullstack Developer Case Study** assignment.

---

##  Features

 **PDF Rendering:**  
Displays the official *Maersk Q2 2025 Interim Report* using `pdfjs-dist`.

 **Interactive Highlighting:**  
Click the `[3]` reference in the right sidebar to highlight  
**"Gain on sale of non-current assets, etc"** in the PDF.

 **Responsive Design:**  
Works on desktop, tablet, and mobile — the layout switches between side-by-side and stacked view.



 **Modern Tech Stack:**  
React + Vite + pdf.js + optional TailwindCSS (for styling).
